# NURMADOG

Процедурная 3D-модель бойца (бойцовый пёс / антропоморфный персонаж) в формате **GLB (glTF 2.0)** со **скелетом (костями/armature)**.

## Что внутри

- `nurmadog.glb` — одна сетка (~857 вершин, 2 материала: тело и экипировка), стоит на y = 0
- **17 костей**: Root, Spine, Head, уши, руки (плечо/локоть/перчатка ×2), ноги (бедро/голень/стопа ×2)
- **Skinning**: атрибуты `JOINTS_0` / `WEIGHTS_0` (до 4 костей на вершину, веса сумма = 1), плавные зоны перехода в суставах
- `inverseBindMatrices` — инверсные матрицы привязки
- Анимация **Idle** (3 с, 30 fps): подскоки, раскачивание рук/ног, повороты головы и стоп

Готовая модель `NURMADOG` в открытых источниках не найдена, поэтому построена процедурно в `build_nurmadog.py` (Python + numpy + pygltflib, без Blender).

## Сборка

```bash
python3 build_nurmadog.py   # создаёт nurmadog.glb
```

## Интерактивный превью (браузер)

```bash
npm install                 # ставит three.js
npm start                   # сервер на http://localhost:8080
# открыть preview/index.html
```

Сервер отдаёт `nurmadog.glb` по относительному пути, модель загружается через `GLTFLoader`, анимация запускается автоматически.

## Структура репо

```
build_nurmadog.py   # генератор модели (источник)
nurmadog.glb        # готовая модель с костями и анимацией
preview/            # трёх.js вьювер + локальный сервер
README.md
```
