# САСНЫЙ — «Кто такой Сасный» (30 сек, 9:16)

Вертикальный мультик в стиле TikTok / Reels: два персонажа-карикатуры, свой бит,
звуковые эффекты, глитч-переходы и текст поверх кадра.

**Готовый файл:** `video/out/sasny_mma_30s.mp4` — 1080×1920, 30 fps, H.264 + AAC, ~30.9 сек.

## Что внутри

| # | Тайминг | Сцена |
|---|---------|-------|
| 1 | 0.0–4.9 | Хук: «КТО ТАКОЙ САСНЫЙ?», плашки «любимец / хейт» |
| 2 | 4.9–10.8 | Бенуа Сен-Дени — любимый боец, «бывший спецназ» |
| 3 | 10.8–16.5 | Стиль: давление, темп, мясорубка, ноль возни |
| 4 | 16.5–21.6 | Хейт: «нурмадоги» (мнение Сасного), Хабиб перечёркнут |
| 5 | 21.6–26.0 | VS: «Бенуа остановил бы Хабиба» + «проходные по стилю» |
| 6 | 26.0–30.9 | Вопрос: «Снимать ещё такое?» + опрос в комментах |

Звук: озвучка (RU), синтезированный бит (140 BPM), панчи, стампы, вжухи, райзеры,
глитчи и UI-блипы — всё сгенерировано кодом, без стоковых сэмплов.

## Как пересобрать

```bash
cd video
pip install pillow numpy scipy imageio imageio-ffmpeg
bash build.sh
```

* `scripts/voice.py` — нарезка озвучки, таймлайн, лёгкое ускорение под 30 сек
* `scripts/audio.py` — синтез бита и SFX, дакинг под голос, loudnorm −14 LUFS
* `scripts/fx.py` — типографика, глитч, зерно, виньетка, спидлайны
* `scripts/render.py` — сцены и рендер кадров прямо в ffmpeg
* `scripts/plan.py` — единый EDL: сцены, биты, удары (используется видео и звуком)

Ассеты: `video/assets/*_src.png` — исходные карикатуры, `*_cut.png` — вырезанные
персонажи, `bg_*.png` — сгенерированные фоны.
