# PS5 Boot Experience for Roblox Studio

Готовый, серверно-защищённый интерактив для Roblox Studio: в мире автоматически появляется оригинальная консоль в стилистике **PlayStation 5**, игрок наводит центр экрана на неё, удерживает **E**, после чего запускаются анимация корпуса, световой boot-эффект, локальная кинематографичная камера и финальная темнота.

> Модель строится из стандартных Roblox `Part`/`WedgePart` во время запуска. В репозитории нет скачанных marketplace-моделей, чужих текстур, логотипов или аудио. Это делает проект лёгким, контролируемым и пригодным для дальнейшей стилизации.

## Что уже сделано

- **Точное наведение:** интерфейс появляется только когда игрок находится в радиусе и центральный луч камеры реально попадает в консоль.
- **Удерживание `E` / `ButtonX`:** современный кастомный HUD, а не стандартный устаревший prompt.
- **Защита на сервере:** клиент не может включить консоль одним RemoteEvent — сервер повторно проверяет дистанцию, препятствия, единственного владельца удерживания и реальную длительность удерживания.
- **PS5-inspired модель:** белые панели, центральное чёрное ядро, вентиляционные прорези, порты, слот, световая вертикаль и подиум создаются кодом.
- **Кинематика:** игроку, который включил консоль, блокируется управление, камера плавно проходит четыре ракурса, корпус раскрывается и загорается LED.
- **Финальный blackout:** по умолчанию экран остаётся полностью чёрным, как было запрошено. Это удобная точка для телепорта, загрузки уровня или следующего ролика.
- **Без глобального camera lock:** остальные игроки видят включение модели, но не получают чужую камеру или чёрный экран.
- **Без beta API и внешних зависимостей:** используются стабильные Luau/Roblox сервисы и стандартный Rojo-проект.

## Установка одной кнопкой — Studio Plugin

Если нужен именно готовый файл плагина, используйте [`plugin/PS5BootInstaller.rbxm`](plugin/PS5BootInstaller.rbxm). Это локальный плагин Studio: установите его через **Plugins → Manage Plugins → Install Local Plugin**, откройте вкладку **PS5 Boot** и нажмите **Install PS5 Boot Experience**. Он сам добавит все скрипты в текущий place, без Rojo. Подробности — в [`plugin/README.md`](plugin/README.md).

## Быстрый запуск через Rojo

Проект также подготовлен для [Rojo](https://rojo.space/), что является удобным профессиональным способом хранить Luau-код в Git.

1. Откройте в Roblox Studio **Baseplate** или свою карту. На карте нужна поверхность и `SpawnLocation`, откуда можно дойти до точки `0, 0, -18`.
2. Установите совместимую версию Rojo и запустите в корне репозитория:

   ```bash
   rojo serve
   ```

3. В Roblox Studio установите плагин Rojo, нажмите **Connect** и выберите запущенный сервер.
4. Нажмите **Play**. `Bootstrap.server.lua` сам создаст `Workspace.PS5Console` и `ReplicatedStorage.PS5BootRemotes`.
5. Подойдите к консоли ближе чем на 10 studs, наведите перекрестие на неё и удерживайте **E** около 1.65 секунд.

### Как устроено в Studio

```text
ReplicatedStorage
├─ PS5BootShared
│  └─ ConsoleConfig                 (ModuleScript)
└─ PS5BootRemotes                   (создаётся сервером во время Play)
   ├─ Interaction                    (RemoteEvent)
   ├─ Cinematic                      (RemoteEvent)
   └─ ConsoleModel                   (ObjectValue)

ServerScriptService
└─ PS5BootExperience
   ├─ Bootstrap                      (Script)
   └─ Console
      ├─ ConsoleBuilder              (ModuleScript)
      └─ ConsoleController           (ModuleScript)

StarterPlayer
└─ StarterPlayerScripts
   └─ PS5BootExperience
      └─ ConsoleClient               (LocalScript)
```

`default.project.json` создаёт именно эту структуру при синхронизации Rojo. Если Rojo не используется, скопируйте файлы в соответствующие объекты Studio с теми же именами и типами.

## Настройка

Весь игровой баланс находится в [`src/shared/ConsoleConfig.lua`](src/shared/ConsoleConfig.lua):

```lua
Interaction = {
    MaxDistance = 10,
    HoldDuration = 1.65,
},

Cinematic = {
    BlackoutAt = 6.35,
    BlackoutPersistenceSeconds = 0,
},
```

### Вернуть игрока в игру после чёрного экрана

Текущее значение `BlackoutPersistenceSeconds = 0` означает **постоянную темноту**. Для демонстрации, где после ролика надо вернуть обычную камеру и управление, установите, например:

```lua
BlackoutPersistenceSeconds = 2.5,
```

В полноценной игре лучше оставить `0` и в момент чёрного экрана запустить свой переход: `TeleportService`, загрузку карты, сюжетный GUI или другой серверный сценарий. После принятого включения сервер записывает в модель `Workspace.PS5Console` атрибуты `BootStartedAt` и `BlackoutAt` (время `Workspace:GetServerTimeNow()`), чтобы внешний серверный сценарий мог синхронизировать такой переход без таймеров «на глаз».

### Лицензированный звук включения

По умолчанию аудио намеренно отключено:

```lua
Audio = {
    PowerOnSoundId = "",
    Volume = 0.55,
},
```

Если у проекта есть права на собственный или лицензированный Roblox audio asset, укажите его ID в `PowerOnSoundId`. Не добавляйте чужой boot sound PlayStation без разрешения правообладателя.

### Переместить консоль

Измените `SpawnCFrame` в `ConsoleConfig.lua`. Кинематографичные ракурсы вычисляются относительно `PrimaryPart`, поэтому автоматически корректно работают при любом положении и повороте модели.

## Архитектура и безопасность

| Файл | Ответственность |
| --- | --- |
| `ConsoleBuilder.lua` | Строит консоль и её свет из примитивов Roblox. |
| `ConsoleController.lua` | Серверная машина состояний `Offline → Booting → Online`, валидация удерживания и физическая boot-анимация. |
| `ConsoleClient.client.lua` | Raycast из центра экрана, HUD, ввод, highlight, камера, letterbox и blackout. |
| `ConsoleConfig.lua` | Единая общая конфигурация без server/client-only зависимостей. |

Клиент управляет только визуальным индикатором удерживания. Сервер принимает `Begin` / `Cancel` / `Complete`, но включает консоль лишь при одновременном выполнении всех условий:

1. консоль ещё выключена;
2. игрок находится в разрешённом радиусе;
3. между персонажем и консолью нет препятствия;
4. игрок действительно удерживал действие минимальное время;
5. другой игрок не получил право на включение раньше.

## Проверка перед публикацией

1. В Studio запустите **Test → Start** с двумя игроками.
2. Наведите центр экрана на переднюю часть консоли: должна появиться голубая обводка и панель `E`.
3. Отпустите `E` до заполнения полосы: включение не должно произойти.
4. Удержите `E` полностью: у первого игрока должна запуститься камера, у обоих — анимация корпуса и света.
5. Попробуйте второму игроку удерживать `E` во время запуска: второй запрос должен быть отклонён.
6. Убедитесь, что первый игрок видит чистый чёрный экран в конце, либо задайте положительный `BlackoutPersistenceSeconds` для возврата управления.

## Замечание о бренде

«PlayStation» и «PS5» являются товарными знаками Sony. Код создаёт самостоятельную стилизованную модель и не включает официальный логотип, меш, звук или графику. Для коммерческой публикации проверьте свои права на название, брендирование и любые дополнительные ассеты.
