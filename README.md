# САСНЫЙ — битва чата

Игра для стрима: Бенуа в красном углу слева, Хабиб в синем справа. Использованы все четыре приложенные фотографии. Логотип составлен из фотографий обоих бойцов с названием «САСНЫЙ».

## Играть сразу

Откройте `index.html` в Chrome/Edge — установка и интернет не нужны. Все изображения, стили и скрипты локальные. Или запустите `npm run dev` и откройте http://localhost:3000.

- Нажатие на фотографию даёт бойцу одно очко, увеличивает фото и запускает эффект +1.
- `←` / `A` (Ф) — Бенуа; `→` / `L` (Д) — Хабиб. Удержание клавиши не начисляет повторные очки.
- `F` (А) или кнопка ⛶ — полный экран.
- Кнопка ♫ включает/выключает синтезированный звук. По умолчанию он выключен.
- Первый до 100 побеждает. Дальнейшие голоса блокируются. Появляется победитель, затем приложенное фото проигравшего и кнопка «Повторить матч».
- «Новый матч» внизу сбрасывает очки с подтверждением, если матч уже начался.
- Очки не сохраняются после закрытия или перезагрузки.

**Это ручной счётчик, а не подключение к TikTok.** Зрители пишут имена в чате, ведущий начисляет очки кликами или клавишами. Автоматическое чтение чата не реализовано. Надпись LIVE — оформление, не индикатор подключения.

## Windows .exe

Готовый exe в этой Linux-среде не собран: сеть запрещает загрузку Electron с домена, на который перенаправляет GitHub. Конфигурация сборки подготовлена, но результат Windows-сборки ещё не проверен.

### На Windows
1. Установите Node.js 22 LTS.
2. Скачайте/распакуйте весь проект.
3. Запустите `build-windows.bat` (для сборки нужен интернет).
4. После успешной сборки получите `release/SASNY-Game.exe` — переносимое приложение Windows x64 без установщика. Node.js на компьютере игрока не требуется.

Или в терминале: `npm ci`, `npm test`, `npm run build:win`.

### GitHub Actions

В проект добавлен `.github/workflows/windows.yml`. После публикации изменений в ветку `arena/0936f096-nurmadog` сборка запускается автоматически. Также можно выбрать **Actions → Build Windows game → Run workflow**, указав эту ветку. В завершённом запуске скачайте артефакт **SASNY-Windows**, распакуйте ZIP и запустите `SASNY-Game.exe`.

Приложение не подписано цифровым сертификатом; Windows может показать предупреждение SmartScreen. Сборка без редактирования ресурсов exe используется для переносимости; фирменный логотип виден в игре и окне, но значок самого exe может остаться стандартным Electron.

## Проверки

`npm test` — 5 автоматических тестов: начальное состояние, победа обоих бойцов ровно на 100, блокировка голосования после победы, правильные фото победителя/проигравшего, реванш и клавиатура. UI-логика проверена в jsdom; реальный браузер и Windows exe в этой среде не проверены.

`npm audit` сообщает о 6 умеренных уязвимостях в транзитивных инструментах сборки Electron Builder. Высоких уязвимостей на момент установки нет; принудительное понижение builder не применялось.
